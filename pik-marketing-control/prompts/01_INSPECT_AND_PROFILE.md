# PHASE 1 — INSPECT + PROFILE

Read the Master Prompt first.

Do NOT build the UI.

1. Inspect repository.
2. Find source Excel and existing Apps Script files.
3. Read PRD/specification.
4. Profile sheets, rows, headers, data types, duplicates, missing values, formulas and relationships.
5. Identify migration risks.
6. Create/update:
   - docs/DATA_PROFILE.md
   - docs/MIGRATION_MAPPING.md
   - docs/IMPLEMENTATION_PLAN.md
7. Do not run real migration.

Only ask if a materially important business decision cannot be inferred.
