# PHASE 6 — QA + DEPLOYMENT

Verify:
- database initialization
- migration counts
- unresolved issues
- authentication/authorization
- CRUD
- PO calculations
- follow-up logic
- dashboard
- responsive UI
- audit log
- performance
- no fake business data
- no critical console errors

E2E:
Login → Dashboard → Customer → Lead → Activity → Follow Up → PO → Delivery → Return → Dashboard

Then prepare deployment documentation. Do not claim completion until the checklist passes.
